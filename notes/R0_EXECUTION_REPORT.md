# R0 Engineering Execution Report — 2026-10-17

## Environment

- Runtime: Linux CPU, PyTorch 2.10.0+cpu, VTK 9.6.2, OpenCV 4.13.0.
- No CUDA GPU detected. Blender absent. A separate connected VPS: ~929 MiB RAM, no Torch or Blender. Not used for training or rendering.
- Therefore all real training and inference evidence in this report is **CPU only**.

## What actually ran

- Three deterministic VTK real-3D camera setups: portrait, forest, village. 4 successive frames each = **12 images** with colors, z-buffer, reconstructed normals, semantic class mask, line, and current→previous rigid-avatar motion fields.
- Smoke labels are generated by OpenCV algorithms, **not** a licensed Ghibli teacher model.
- **A**: 11,780,931 trainable params, theoretical FP16 weight storage 22.47 MiB.
- **B**: 6,204,707 trainable params, theoretical FP16 weight storage 11.83 MiB.
- Model includes capped <=256-token pooled self-attention at its bottleneck. No text encoder or diffusion base weights.
- Both routes: real 40-step PyTorch training, checkpoint saving, validation forward pass.
- Separate A 2-step temporal loss training also passed, using scene motion buffers.
- pytest: 10 tests passed (model shapes/capacities, smoke gating, nontrivial depth/semantics, time warp direction, backprop, rights gate, dataset split audit).

## Smoke labels: held-out frame comparison (NOT fair scene holdout)

After 40 gradient steps on synthetic NPR labels:

| Metric | Route A | Route B |
|---|---:|---:|
| Mean absolute error vs synthetic NPR target | 0.04368 | 0.06262 |
| Motion-warped residual MAE across nine adjacent-frame pairs | 0.002321 | 0.002628 |

**Interpretation**: these figures establish that the training and metric pipelines execute. The target is a deterministic NPR function of the source; Route B changes the source with a coarse palette, and could lose information. This test is NOT a fair architecture-quality ranking. The validation set is a nearby frame from scenes in training, so it proves no generalization. Motion tests are predominantly static-scene camera-locked footage with a small rigid puppet translation; they do not validate occlusions, fast motion, or production temporal consistency.
